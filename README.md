# 📊 Power BI Sales Dashboard

![Dashboard Preview](dashboard-main.png)

## 🔍 Overview

This project showcases an interactive Power BI dashboard built using the Global Superstore dataset to analyze sales, profit, and business performance.

## 📌 Key Features

* KPI Cards (Sales, Profit, Margin)
* Region & Category Filters
* Drill-through Product Details
* Sales Trend Analysis
